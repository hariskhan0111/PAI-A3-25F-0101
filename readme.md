# README

## How to Run
I use ubuntu and so to run this assignment, open the project folder in the terminal, activate the virtual environment, and start Jupyter Notebook:

```bash
source jupyter-env/bin/activate
jupyter notebook
```

Open the notebook and run the cells in order, starting from the first question.
